# Music Visualizer 音乐可视化

纯浏览器端的本地音乐可视化程序：加载音频文件，实时渲染 5 种可视化模式（每种均有经典 / Pro 双预设），支持一键离线渲染导出 MP4 视频（GPU 硬件编码）。

**无后端、无上传、无追踪**——音频和视频全部在本机浏览器内处理。

## 功能

### 5 种可视化模式（1-5 切换）
| 模式 | 经典预设 | Pro 预设 |
|---|---|---|
| 频谱 | 渐变柱 + 峰值帽 + 尾迹 | 多色渐变柱 + 侧高光 + 变色尾迹 |
| 环形 | 放射频谱 + 波形环 | 双层反向旋转 + 频段跳动点 + 发光 |
| 波形 | 多层残影叠加 | 双层交织填充 + 呼吸缩放 |
| 星云 | 自由环绕粒子 + 节拍迸发 | 频段轨道环 + 彗尾流星群 |
| 瀑布 | 声谱热图滚动 | 色温映射 + 底部雾化渐隐 |

### 博主模式（B 键）
隐藏全部操作 UI，只留歌曲信息层（歌名/进度/序号/下一首），两种布局（分散式 / 顶部卡片，Shift+B 切换），专为录屏设计。

### 一键渲染视频（R 键）
- **离线逐帧渲染**（不是录屏）：输出与实时画面完全一致
- GPU 硬件编码（WebCodecs，Chrome/Edge 最佳），失败自动回退 CPU
- 分辨率最高 4K、帧率最高 120fps、码率最高 100Mbps
- 音频格式转换（AAC/MP3/Opus/直通）、码率/声道/重采样可调
- HDR 导出（10bit AV1/HEVC + PQ，视显卡支持）
- 输出自动校验：帧率 / 视频码率 / 音频码率达标报告
- 全程日志（可导出 txt 排查问题）

### 个性化
- 4 套主题色 + 从背景图自动提取主题色
- 自定义背景图 + 可调模糊/压暗
- 灵敏度、节拍强度、拖尾、旋转速度、粒子密度等 40+ 项参数
- 设置分 5 栏：外观 / 可视化 / 播放 / 导出 / 高级

## 快速开始

### 需要
- Python 3（仅用于启动本地静态服务器）或任意静态服务器
- Chrome / Edge（视频导出需要 WebCodecs；Firefox/Safari 可用实时可视化，导出回退 CPU）

### 启动

**Windows**：双击 `启动.bat`

**Linux / macOS**：
```bash
chmod +x start.sh
./start.sh
```

然后浏览器打开 http://127.0.0.1:8080

> 也可以用任意静态服务器：`npx serve .` 或 `python -m http.server 8080`
> 不支持直接双击 index.html 打开（多文件结构需要 http 服务）

### 使用
1. 拖入音频文件（MP3/WAV/FLAC/OGG/M4A，可多选建播放列表；拖图片设为背景）
2. 数字键 1-5 切换模式，Shift+数字切换经典/Pro 预设
3. 按 B 进博主模式预览，按 R 渲染导出视频

快捷键速查：`空格` 播放暂停 · `←→` 快退快进 · `↑↓` 音量 · `B` 博主模式 · `Shift+B` 布局 · `R` 渲染 · `S` 设置 · `F` 全屏 · `L` 列表 · `[ ]` 灵敏度

## 技术栈

纯原生 HTML/CSS/JS（无框架、无构建工具）。核心：

- **实时管线**：Web Audio `AnalyserNode` → 对数分频（96 频段）→ 节拍检测 → Canvas 2D 渲染
- **导出管线**：离线 FFT 复刻（与 AnalyserNode 等效）→ 逐帧渲染 → WebCodecs `VideoEncoder`（GPU H.264/AV1/HEVC）→ ffmpeg.wasm（本地 vendor，仅封装/转码）
- **架构**：主程序通过桥接接口把渲染管线借给导出模块复用，所见即所得

## 目录结构

```
├── index.html          # 主程序
├── js/
│   ├── offline-analysis.js    # 离线频谱分析（含 Node 单元测试）
│   ├── overlay-render.js      # 导出视频的信息层绘制（含单元测试）
│   └── video-export.js        # 视频渲染导出
├── vendor/             # ffmpeg.wasm 本地化（离线可用）
├── 启动.bat / start.sh # 启动脚本
└── DEVELOPMENT.md      # 开发文档（架构/坑/修改指南）
```

## 已知限制

- 4K 渲染需要 1-2GB 内存，低配设备建议 1080p
- 120fps 需要显卡编码器支持 H.264 level 6.2
- HDR 输出为 SDR→HDR 映射（非原生 HDR 素材）
- 渲染耗时随分辨率/帧率/时长线性增长，GPU 编码下 3 分钟歌曲 1080p 约半分钟
